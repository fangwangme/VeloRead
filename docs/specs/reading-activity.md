# 阅读统计与自动打卡

> 状态：✅ 已实现（Web / IndexedDB 与 Tauri / SQLite）。
> 相关：[pacer](pacer.md)、[reader-view](reader-view.md)、[platform-and-storage](platform-and-storage.md)

## 1. 目标

统计只回答真实的阅读行为：读了多久、读过多少正文、连续读了多少天，以及当天是否达到目标。
加载等待、打不开的书、后台挂机和排版重排都不能制造数据。

## 2. 有效阅读时间

每秒计时前必须同时满足：

- Reader 已完成创建且没有打开错误；
- 页面可见且窗口有焦点；
- 目录、排版设置和本书 Pacer 设置面板均未打开；
- 当前页累计不超过 300 秒，避免静止挂机无限增长。

会话每 15 秒尝试写入一次，切到后台和离开 Reader 时也会 flush。写入成功后才从内存 buffer
扣除本次快照；失败时保留 buffer，等待下一次重试。会话日期使用用户本地日历日，不使用 UTC 截断。

## 3. 已读阅读量

- 只统计真实离开的可见页；首次 location、相同 CFI 的重复回调不计字。
- 页面至少停留 3 秒，或 Pacer 从首块开始、未 seek / 跳块地实际走完整页，才把该页正文计入会话。
  点击末尾文字后只播放最后一块、或手动跳到页尾，都不能把整页计为已读。
- 风格、字号、分栏、flow 和 resize 引发的 relocation 在抑制窗口内不计字。
- 英文按 `Intl.Segmenter` 的词计数；汉字、平假名、片假名与谚文按 Unicode 字素计数，
  分别存为 `latinWordsRead` 与 `cjkCharactersRead`，不得合并成含义不明的“字数”。
- 全角标点、引号、Emoji 与符号不计入任何阅读量。
- 阅读量来自当前视口真实文本 Range；取不到正文时记 0，不使用固定的“每页 250 词”兜底。
- script、style、SVG、canvas、object、图注和 caption 不计入正文。

## 4. 聚合与删除

两份存储实现必须保持一致：

- 正时长不足一分钟时显示 1 分钟，之后按分钟四舍五入；
- 同一本书同一天的 session 以稳定 id 累加时长、英文词与 CJK 字符；
- 删除书籍同时删除其 reading sessions，统计中的书数、时长和阅读量立即消失；
- 连续天数允许今天尚未阅读，但昨天仍处于连续链；跨日判断使用本地日期。

## 5. 打卡

打卡由有效阅读分钟数自动产生，不提供手动签到：

- 默认目标 15 分钟，可在书库的应用设置中选择 10 / 15 / 20 / 30 / 45 / 60 分钟；
- `minutes >= goal` 为已达标，`0 < minutes < goal` 为阅读中；未来日期不参与；
- 修改目标只重新计算展示，不改写历史 session；
- 统计弹窗分「数据总览 / 阅读打卡」两个子页。打卡页展示今日进度、连续天数、当月达标天数和月历。

## 6. 阅读进度不是阅读统计

恢复位置单独存 `ReadingProgress`：精确 EPUB CFI + 最后已知百分比，location 变化后 400ms 防抖写入，
离开 Reader 时再 flush。百分比未知时保留旧值；写入成功前不得清空待保存位置。

当前仍是开发期，v3 之前的混合 `wordsRead` 没有可靠方式拆成两类。升级旧开发库时重建按书设置与
阅读 session，不保留这两类未发布数据；书籍、原文件、封面和阅读进度保持不动。
