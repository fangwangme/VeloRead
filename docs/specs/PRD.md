# VeloRead 产品需求文档 (PRD)

> 版本：v2（2026-08-15 重写）
> 上一版是浏览器端定位，本版改为 macOS 桌面应用，并补入划线摘抄与背单词数据流。

## 1. 产品定位

**VeloRead** 是一款桌面 EPUB 阅读器，目标是**替代 Kindle 成为日常英文阅读的主力工具**。

三条主线，缺一不可：

1. **读得进去** —— 排版和翻页体验对得起长时间阅读
2. **读得更快** —— Pacer 引导视线移动，训练打破默读习惯
3. **读完有沉淀** —— 划线摘抄能导出成纯文本，生词能变成可复习的卡片

**核心理念**：像 Apple Books 一样优雅，像 Kindle/Readwise 一样能沉淀，像专业速读工具一样高效。

## 2. 形态与技术约束

- **交付形态**：macOS 桌面应用（Tauri v2 + WKWebView），后续可出 Windows / Linux 包
- **前端**：React 19 + TypeScript + Vite + Tailwind 4；书页渲染基于 epub.js（EPUB 本质是 XHTML+CSS）
- **本地存储**：书籍文件落磁盘由应用管理；元数据、阅读进度、划线、词表、词典入本地 SQLite
- **隐私**：默认全本地，不上传任何书籍或笔记内容。仅在用户显式开启的联网功能（如在线词典、LLM 释义）中发起网络请求
- **平台抽象**：`storage` / `fs` / `dict` 三类能力走适配层，保留浏览器构建目标用于快速迭代与线上 demo
- **开源**：以开源发布为前提做技术决策 —— 不引入需要闭源服务或付费依赖的方案

## 3. 功能需求

### 3.1 书库 (Library)

- 拖拽或选择导入 `.epub`；支持指定一个"书库文件夹"并识别其中的书籍
- 解析并展示元数据（标题、作者、封面）
- 排序：最近阅读 / 导入时间 / 标题
- 删除书籍（区分"移出书库"与"删除文件"）
- 阅读进度、总进度百分比在书架可见

### 3.2 阅读器 (Reader)

- 分页（paginated）与滚动（scrolled）两种模式，支持单页 / 双页
- 目录（TOC）导航，可跳转章节；显示当前页码、章节剩余
- 阅读进度以 CFI 持久化，重开自动定位
- 排版可调且**按书记忆**：字号、字体、行高、字间距、连字符、页边距
- 主题：明亮 / 暗黑 / 羊皮纸(Sepia)，跟随系统；切换无闪烁
- 翻页动效：平滑滑动或仿真翻页
- 键盘操作完备：翻页、跳章、开关 Pacer、退出

### 3.3 阅读提速器 (Pacer)

- 按设定 WPM 自动推进高亮块，引导视线移动
- 英文按词组切分（约 3 词一次注视），中日韩按字数切分
- 行感知分组：高亮块不跨行断裂
- 翻页后自动在新页续接，不丢位置
- 控制项：WPM（100–1000）、播放/暂停、回到页首、引导样式（高亮 / 下划线 / 加粗）
- **阅读速度统计**：记录实际 WPM 与阅读时长，可查看趋势（这是"训练"而不只是"功能"的关键）

### 3.4 划线摘抄 (Highlights) —— 对齐 Kindle

- 选中文本 → 划线，支持多种颜色 / 加笔记
- 划线持久化并锚定到 CFI，重开书能准确回到原位
- 书内划线列表视图，可跳转、编辑、删除
- **导出为纯文本**，格式与 Kindle `My Clippings.txt` 对齐（书名 / 作者 / 位置 / 时间 / 正文），
  保证既有 Kindle 摘抄处理链路（Readwise、Obsidian 脚本等）可以直接消费
- 支持指定一个导出目录，划线变更时可增量追加/重写该文件，无需每次手动导出
- 附加导出格式：Markdown（按书分文件，便于进笔记库）

### 3.5 划词与生词本 (Vocabulary)

- 选中单词 → 即时查询本地词典，弹出释义（英英为主，可选中文）
- 词形还原：查询前做基本还原（复数、时态、比较级），避免查不到
- 两个方向的操作：
    - **标为认识**：加入熟词表，后续不再提示
    - **标为生词**：加入生词表，记录**所在句子作为例句**和出处（书名 + 位置）
- 生词本页面：列表、筛选、按书查看、删除
- 自动标注（可开关）：基于常用词频表（3000/5000），标出超出词表的高级词并给出简短释义

### 3.6 背单词数据流 (Flashcards)

生词本不是终点，必须能进入间隔重复系统：

- **导出 Anki**：生成 `.apkg` 或 CSV，字段包含 单词 / 释义 / 例句（原文句子）/ 出处 / 音标
- **AnkiConnect 直连**（可选）：检测本地 Anki 运行时，一键推送到指定牌组，避免手动导入
- 已导出的词做标记，支持增量导出

## 4. 非功能需求

- **性能**：打开 >20 MB 书籍无明显卡顿；划词查询响应 < 50 ms；自动注解渲染延迟 < 100 ms
- **词典**：本地词典以 SQLite 存储并建索引，不整包载入内存
- **数据安全**：书籍与笔记存在用户可见的目录中，卸载应用不丢数据；提供一键导出全部数据
- **可访问性**：所有阅读操作可用键盘完成；释义提示不依赖 hover
- **应用体积**：安装包目标 < 30 MB（不含词典数据）

## 5. 后续规划 (Roadmap)

- LLM 长难句解析与释义（用户自带 API key，默认关闭）
- iPad / iOS 版本
- 跨设备同步（进度、划线、词表；优先 iCloud Drive / 用户自选目录同步，而非自建服务）
- PDF 支持
- 阅读统计看板（速度趋势、词汇增长）
